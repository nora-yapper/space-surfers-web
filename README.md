# Space Surfers (web)

The website and the browser (keyboard) build of Space Surfers, a body-controlled hoverboard game made for Interactive IV, Project 02 at RIT Croatia by Sven Culjak, Dinmukhamed Beisenov and Nora Miskulin.

- `index.html`: the landing page.
- `play/`: the Godot 4.7 web export (single-threaded, so it needs no special server headers).

The full game is played standing on a board in front of a Kinect v2 camera, which needs a Mac and our tracker. This repo only holds the keyboard version for the browser.

3D models: our own, plus open-licensed models from Sketchfab (CC BY 4.0) and Poly Haven (CC0). All authors are credited on the in-game credits page.
